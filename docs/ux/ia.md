# LingEdge 信息架构（IA）· Admin / Console / 官网

> 属于 `docs/ux/ux.md` 的组成部分。覆盖基线第 26 章第 10 项「Admin / Console 菜单及页面设计」的**导航层**。页面级线框见 `screens.md`，CLI/TUI 见 `cli-tui.md`，官网见 `website.md`。

## 0. 阅读约定

**阶段标签**（沿用 PRD §10，M1 即 PRD 的 MVP）：

| 标签 | 含义 |
|---|---|
| **M1** | MVP（Tools + Server + 基础 Admin + 官网框架 + 可运行 Node）。随 M1 交付并可在真实环境验证 |
| **M1 子集** | M1 交付，但范围小于基线列出的全部能力（说明写在「备注」） |
| P2 | 官网 CMS 与 CDN 补强（ACME、预热、通知告警、配置模板…） |
| P3 | DNS、调度与监控（含 Reporter、地域/运营商分析、报表） |
| P4 | WAF/CC 与四层代理 |
| P5 | 商业化与完整发布（Console、计费、工单、插件、Docs、Status） |
| P6 | 高级能力（L2 缓存、DNSSEC；HTTP/3、边缘计算须先技术验证） |

**菜单可见性公式**（Admin 与 Console 通用，PRD FR-31、FR-24、FR-37）：

```
菜单/页面可见  =  该页面所属后端模块「已交付」   ← 能力清单由 Server 下发，前端不自行猜测
              ∧  当前身份拥有对应权限点          ← 无权限：不显示菜单，直访路由给 403 页
              ∧  当前运行模式允许                ← 自用模式隐藏商业功能（D-3）
```

**未交付模块不渲染**：本文列出完整的 17 个一级菜单是为了冻结信息架构；M1 的真实界面**只出现标 M1 的菜单与页面**，其余既不显示灰色占位也不显示「敬请期待」假页面（NFR-1、FR-31）。一级菜单下若 M1 页面数为 0，则整个一级菜单不显示。路线图信息只出现在 Docs/官网更新日志，不放进后台导航。

**重复入口的处理**：基线中同一能力出现在多个菜单（例：审计日志、访问日志、缓存、角色权限）。UX 规定「**一个能力只有一个规范页面（canonical）**，其他入口是带预置筛选的别名路由或站点内范围视图，共用同一组件，不复制页面」。别名在下表「备注」中标「别名」。

## 2. Console（用户控制台）— 10 个菜单（P5）

Console 是**租户视角**，与 Admin 是不同前端入口、不同构建产物、不同路由表（FR-37）。站点详情等页面复用 `frontend/shared` 组件，但数据范围是「当前租户」，且**没有任何节点/集群/调度/系统级入口**。

## 4. 权限隔离在导航层的体现

导航层只是权限的**呈现**，真正的隔离由服务端强制（FR-19、NFR-8）。UX 规则：

1. **两个入口、两个产物**：Admin 与 Console 是独立入口（建议不同域名/路径前缀与不同会话 Cookie 作用域，最终由安全文档定）。租户账号在 Admin 入口登录一律被拒并给出中性提示「该账号无权访问此入口」，**不泄露「该账号存在」之外的信息**。
2. **路由表按入口静态拆分**：Console 构建产物**不包含** Admin 专属路由、菜单与接口调用（FR-37 可验证项）；不是「运行时隐藏」。
3. **菜单 = 能力 ∧ 权限 ∧ 模式**（见 §0 公式）。权限变化后用户下次刷新/重新获取能力清单时菜单随之变化；不依赖前端缓存的菜单。
4. **直访无权路由**：渲染统一「403 无权限」页，显示所需权限点名称与「联系管理员」，并提供返回工作台；**不渲染半成品页面再被接口 403 打断**。未交付模块的路由显示「404 页面不存在」而非 403（避免暗示存在）。
5. **页内操作粒度**：用户可「查看」但不可「操作」的页面：操作按钮**禁用并附 Tooltip 说明缺少的权限**（有利于学习与排障）；用户连「查看」都没有的页面：整页不可达。例外：涉及节点内部信息、他人 Token、私钥的字段永远不下发，也就谈不上禁用。
6. **Admin「代管租户」**：M1 只有默认租户（D-13），管理员在 Admin 里代默认租户操作。顶栏固定显示**代管横幅**（`acting-as-banner`）：「正在以管理员身份操作租户：默认租户」。P5 多租户后，顶栏出现租户切换器；切换到非默认租户时横幅变为强调色，且**所有写操作的审计记录带「代管」标记**；横幅不可关闭。
7. **API Token 作用域**在创建页以与菜单相同的分组呈现（站点/证书/缓存…），租户 Token 的作用域选择器里**没有**节点/集群/系统类选项。
8. **全局搜索**（⌘K / Ctrl+K）只返回当前身份可见的对象与页面，且受租户边界约束；不索引日志正文。
9. **多标签页**：切换租户/退出登录时关闭全部标签并提示未保存更改，防止跨租户残留视图。
