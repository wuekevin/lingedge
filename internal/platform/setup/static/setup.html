凌界云 LingEdge · 安装向导

Server 正处于 setup mode：尚未完成安装，除本页与 /api/v1/public/setup/* 外所有接口均返回 503。

向导的图形界面随 Admin 前端交付（Story 1.37）。本页是内嵌的最小占位页；后端接口已完整可用，所有接口都需要请求头 X-Setup-Token（安装器在终端一次性显示的 setup token）。默认只监听 127.0.0.1:8080，远程访问请使用 SSH 隧道。

步骤

  1. 环境检查 POST /api/v1/public/setup/checks
  2. MySQL PUT /api/v1/public/setup/database（可用临时管理员凭据创建专用库与三类账号）
  3. Redis PUT /api/v1/public/setup/redis
  4. 数据库初始化 POST /api/v1/public/setup/initialize
  5. 创建管理员 POST /api/v1/public/setup/admin（口令由你设定，无任何默认口令）
  6. 系统基础配置 PUT /api/v1/public/setup/system
  7. 内部身份与密钥 POST /api/v1/public/setup/keys
  8. 完成 POST /api/v1/public/setup/complete

也可以使用无头路径：lingedge-server setup --from-file <0600 的 YAML>。进度查询：GET /api/v1/public/setup/status。
